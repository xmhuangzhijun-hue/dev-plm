# 轻单（示例）

本目录仅包含虚构示例项目的开发资料与 API 契约，没有业务应用的实际代码或真实部署。

- `project.yaml`：项目定位、阶段、代码位置的唯一真源。仓库地址和本机路径均为虚构。
- `onboarding.yaml`：第一天接手所需的技术、启动、数据库、配置和负责人说明。命令描述假设的目标仓库，不是本目录可执行的业务代码。
- `requirements/`：用户原话、当前理解、验收条件和需求状态。
- `ui/`：页面与可交互毛坯的来源。
- `data/fields.yaml`：字段候选、规则与关联。
- `api/openapi.json`：接口、环境地址、请求响应示例及错误码的唯一真源。所有 `.invalid` 地址均不可用于真实访问。
- `records/`：按开发环节和环境查找的过程记录。
- `tests/`：关联需求的验收说明与虚构结果。

所有配置只写变量名、用途和登记来源；不保存秘密。示例登录字段和令牌都使用明确不可用的占位文本。

网页负责展示和采集输入；后端负责身份、归属、校验、幂等、版本检查和保存。未来客户端共享同一 API。
