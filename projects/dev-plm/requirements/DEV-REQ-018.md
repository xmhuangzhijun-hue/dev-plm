# 多个项目资料目录可以外置

## 用户原话

> 支持**多个数据根**（公开示例 + 私有真实数据）同时载入，项目 id 冲突时报错而不是静默覆盖；

## 当前理解

CLI 重复 --data-root 或 DEVPLM_DATA_ROOTS 指定多个资料根，默认仍为 projects；共享加载器同时供 build 和 sync 使用，网页只展示相对资料路径。
