# dev-plm 自身的项目档案

这是本工作台的第一个真实项目，`example: false`。其余明确标为示例的项目不可与本档案混淆。

先看 `requirements/` 中保留的原12条需求与后续迭代，再看 `changes/` 中六轮变更。第一轮无Git历史，其后变更关联真实本地提交；本轮进度以CHG-006与实际回执为准。

现有源码在仓库 `src/`，构建入口 `build.py`。运行 `python build.py` 后双击 `site/index.html`；离线站不需要后端、数据库或网络。已有依赖与全仓库操作方法见仓库根 README。

`design/stack.md`、`design/database.md` 保留设计背景。FastAPI/PostgreSQL已在本机运行，契约0.3.0比较通过；React协作前端尚未实现。契约中 `.invalid` 地址是设计占位，实际本机/私网访问按 docs/private-network.md，私有主机地址不写进公开契约。

本轮原话来源是用户提供的十二条集中清单；不声称已逐一恢复每条最初提出时的历史逐字记录。第2轮历史验收与第三轮实际验收分别记录，不能相互替代。

项目事实由文件维护，数据库只作派生读模型。讨论、认领等数据库协作真源必须导出；没有导出文件就不能在删库后恢复这些内容。设计不会把讨论自动晋升为项目事实。

`releases/`、`incidents/`、`audits/` 当前无新的真实发布、事故或安全审计单，不以填目录为目的编造记录。
