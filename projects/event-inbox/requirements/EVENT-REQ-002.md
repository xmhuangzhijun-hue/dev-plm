# 调用方可以查询自己的收件回执

> 虚构示例，用于说明开发资料的协作方式。

## 用户原话

如果提交后的响应丢了，我希望能拿回执编号确认收到没有，但不能看到其他系统的事件。

## 当前理解

提供按回执编号查询的只读接口。服务从令牌确定调用方，回执不存在或不属于调用方时均返回 404。当前契约只确认收件状态；不报告尚未实现的下游处理结果。查询入口是 API，不新增管理页面。
