# 授权收件，并对重复事件返回同一回执

> 虚构示例，用于说明开发资料的协作方式。

## 用户原话

业务系统会通知订单事件，网络不好时会重发。我想有个接口接住它，重复发送也只记一条，并告诉调用方收到了。

## 当前理解

登记过的调用方先取得短期令牌，再提交事件。服务验证身份并保存事件与回执；相同调用方重发相同事件返回同一回执，不重复入库。相同事件编号或幂等键携带不同内容时返回 409。202 只表示已收件，不代表任何下游处理完成。该服务不需要用户界面。
